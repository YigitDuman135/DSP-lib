# DSP Library
A DSP library built for the sake of learning. Library architecture is:

```
DSP-lib
↳ build:         C builds
↳ inc:           C header files
↳ scripts:       Python golden models, used to validate C models
↳ src:           C source files
↳ test_results:  Test logs
↳ test_vectors:  Test vectors used to test the models
↳ tests:         Tcl tests to validate C models
↳ Makefile
↳ Readme.md
```
